## المقاسات
Android 7.1 / API 25، شاشة أفقية 1024×600، ذاكرة تقارب 1GB. اتجاه عربي RTL. ارتفاع الأزرار 52–56dp وحد أدنى للمس 48dp. زوايا البطاقات 22–24dp والأزرار 16–18dp. عناوين 24–28sp، عناوين البطاقات 19–22sp والنص العملي 16–18sp. هوامش 16–20dp وفواصل 10–14dp.
المحتوى الطويل يمرر داخل منطقته. تبقى خطوط القراءة والقرآن الموجودة. لا تنزيل خطوط عند التشغيل ولا تمويه حي أو حركة زخرفية مستمرة. تفك الصور بأبعاد محدودة خارج مسار الواجهة.

## الإعدادات وحماية الأساسيات
تنظيم الخيارات: استخدام يومي، تشغيل، تخزين وتنزيل، تحديث، حول؛ دون حذف الخيارات القائمة أو تكرارها. تعرض «حول» الاسم والإصدار والتوقيع الكامل. يبقى التشخيص المحلي خلف مدخله القائم.
لا تغيير لمعرف الحزمة أو مفتاح توقيع قائم أو قواعد البيانات أو مجلدات المستخدم. لا تصفير للإعدادات أو سجل الصيانة أو القراءة. يبقى منطق GPS والمزامنة والتنزيل والوسائط محفوظًا إلا لإصلاح خلل موثق.

## التسليم
توثيق commit والإصدار، نجاح البناء والفحوص القائمة، مشاهدة لقطات 1024×600، والتحقق من الحزمة وAPI والتوقيع وSHA-256. تحفظ هوية ملفات Drive وروابط التحديث ولا يعلن تحديث قبل وجود APK صحيح. الحالة «جاهزة لتجربة الشاشة» حتى قبول المالك بعد الاختبار الفعلي.
هذا المرجع محفوظ للاستخدام في التطبيقات القديمة والجديدة؛ وجوده لا يعني اكتمال التنفيذ أو الفحوص.
