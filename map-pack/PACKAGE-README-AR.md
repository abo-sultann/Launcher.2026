# حزمة خريطة السعودية — Launcher 2026

هذه حزمة اختبار مستقلة، ولا تحدّث التطبيق تلقائيًا.

## المحتويات

- `Saudi-2026.map`: خريطة Mapsforge دون إنترنت، بأسماء عربية أولًا وإنجليزية احتياطية.
- `Saudi-2026.poi`: قاعدة بحث محلية للأماكن والعناوين، مع تطبيع الأسماء العربية وفهرس بحث كامل.
- `manifest.json`: مصدر البيانات والإصدارات ونتائج الاختبارات.
- `SHA256SUMS`: بصمات سلامة الملفات.
- `verification/`: تقارير فحص الخريطة وقاعدة البحث.

## التغطية

المملكة العربية السعودية مع هامش صغير للسواحل والطرق الحدودية. تشمل بيانات OpenStreetMap المتاحة: المدن والقرى والطرق والمعالم والخدمات والعناوين ونقاط الاهتمام.

لا تشمل الحزمة حركة المرور الحية أو صور الأقمار الصناعية؛ فهذه البيانات لا تعمل كخريطة ثابتة كاملة دون إنترنت.

## التوافق

تم فتح الخريطة وقراءة بلاطات من الرياض وجدة ومكة والمدينة والدمام وتبوك وأبها باستخدام قارئ Mapsforge `0.25.0` المطابق لإصدار Launcher الحالي. ملف البحث بصيغة POI v4 ويتطلب Mapsforge POI `0.30.0` مع SQLite المضمّن عند دمجه لاحقًا في التطبيق.
